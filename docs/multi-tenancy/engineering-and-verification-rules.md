# Engineering Rules and Phased Verification

## Engineering rules

- Preserve the current Laravel and React architectures; change incrementally.
- Tenant base queries and policies are the only row-authorization path. Controllers do not hand-build tenant `where` clauses.
- Requests may narrow authorized results but never establish tenant identity.
- Use transactions for multi-record writes and allow unrecoverable exceptions to propagate.
- Use intent-revealing names, single-purpose functions, no more than four parameters, and no dead or commented-out code.
- Do not add interfaces, flags, factories, packages, or alternate APIs without a current caller.
- Verify framework/package APIs against installed Laravel 10, Spatie Permission 6, Query Builder 5, and JWT Auth 2.
- Every authored or touched frontend JS/JSX file must contain at most 250 physical lines.
- Preserve unrelated working-tree changes. Do not commit or deploy without explicit instruction.

## Phase verification protocol

For every phase:

1. Run focused backend tests, then the complete backend suite.
2. Run frontend tests, lint, and production build when frontend code is affected.
3. Count all authored frontend JS/JSX lines and enforce the 250-line cap.
4. Inspect both repository diffs and verify no unrelated or destructive change.
5. Run the clean-code guard against production-code changes and fix every finding.
6. Update this document's evidence log before declaring the phase complete.

## Required isolation coverage

- Two companies, including one branchless company.
- List, show, create, update, delete, direct-ID, and altered-filter attacks.
- Tenant-filtered companies, branches, customers, users, roles, and parameters.
- Ticket logs and attachment downloads through parent ticket scope.
- Export contents and dashboard aggregates from the authorized ticket query.
- Internal action permissions independent of row scope.
- Disabled users and companies, plus invalid or incomplete tenant context.
- Public review expiry, replay, revocation, purpose, and rate limiting.
